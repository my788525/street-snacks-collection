# 街头小吃模拟经营合集

12 款独立网页小游戏，同一个经营内核、不同地域风味与美术：

蛋烘糕 · 广东肠粉 · 西安肉夹馍 · 天津煎饼果子 · 长沙臭豆腐 · 广西螺蛳粉 · 重庆小面 · 武汉热干面 · 东北烤冷面 · 海南清补凉 · 街头炸鸡 · 河北驴肉火烧

## 架构

- `common/` —— 数据驱动的公共游戏引擎（火候 / 对折 / 临期经济 / 变质 / 排队 / 口碑 / 城管 / 探店博主 / 团购外卖预订 / 难度门禁 / 分享卡片）
- `games/<小吃>/` —— 每款游戏一个独立目录，只带一份 `profile.js`（食材、台词、主题、场景、相性），引擎自动接管其余机制
- `index.html` —— 合集首页，12 款导航

每款游戏独立存档、独立解锁进度。

## 本地运行

纯静态站点，任意静态服务器即可：

```bash
cd danhongao
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署（Cloudflare Pages）

纯静态，无需构建：

- 连接 GitHub 仓库
- **Build command（构建命令）：留空**
- **Output directory（输出目录）：仓库根目录 `/`**（或直接留空，默认用根）

部署后首页即 `index.html`（12 款游戏导航）。
